# 磁驱动 iNTA 算法优化：新增公开近邻检索记录

检索日期：2026-11-05。用途：为下一版算法提出可检验的技术区别，补充已有 `outputs/patent_feasibility_2026-11-05/中国发明专利可行性分析.md`，不替代正在进行的六条件正式对照，也不作授权率或自由实施结论。此次仅访问公开资料和公开项目源码，未向外部服务提交用户未公开源码、实验结果或完整技术方案；未修改任何 `.m` 文件。

## 1. 直接结论

**“选背景区域做功率归一化”“前景掩膜辅助照明估计”“分区频谱判断闪烁”“依置信度校正或回退”都已有明显近邻。不能仅增加其中一个模块，就把它命名为已成立的专利创新。** PiSCAT 的公开源码已有矩形 ROI 功率归一化；2020 年论文已有前景分割掩膜参与照明估计；空间闪烁专利甚至明确提出，应避免全帧校正给原本无闪烁区域引入反向闪烁。见下列 S3、S5、S7、S8。

仍值得研究的不是新的名词，而是本应用的可辨识性问题：**同频磁运动存在时，何种独立图像证据足以允许照明校正；何种条件必须回退；局部校正如何避免改变颗粒定位和扩散统计。** 这只是由近邻分析得到的研究方向，尚未证明具有新颖性、创造性或稳定技术效果。它应在现有六条件结果完成后单独开发、冻结并用新数据验证，不能回改本轮预设比较。

## 2. 九项优先核对来源

### S1：磁梯度 + 纯水磁纳米颗粒 + iSCAT 已有直接实验

**标题：** *Real-Time Detection of Single Magnetic Nanoparticle with Interferometric Scattering Microscopy*。作者：Yulong Dong、Feidi Xiang、Yi Ding、Ryszard Buczynski、Wenzhong Liu。首次在线日期 **2026-03-04**；*Small Methods* 10(11), e02180；DOI **10.1002/smtd.202502180**。[出版方记录](https://onlinelibrary.wiley.com/doi/10.1002/smtd.202502180)，[PubMed 元数据](https://pubmed.ncbi.nlm.nih.gov/41778396/)。

已核对出版方作者/摘要和 PubMed 日期：在纯水中用磁场梯度诱导单磁纳米颗粒定向运动，并以 iSCAT 追踪。不能把“磁场加入 iSCAT”作为空白主张。此次未获得全文实验方法，不能据摘要推断它是否完整公开交变磁场的粒径修正、照明分离或本项目预处理。此项为前报告重要近邻的复核，非新增发现。

### S2：利用扩散轨迹重建空间归一化轮廓的近期预印本

**标题：** *Motion-Based Self-Normalisation Enables Precision Nanoparticle Sizing*。作者：D-Dré K.J.M.J. Braam、Daan Wolters、Matz Liebel。arXiv **2607.14761**，v1 **2026-07-16**，此次读取 v2 **2026-10-30**。[版本记录](https://arxiv.org/abs/2607.14761)，[v2 全文](https://arxiv.org/pdf/2607.14761v2)。

已读摘要、全文图 3 相关方法、MSD 方法及补充说明：以不同颗粒轨迹的空间重叠区相互归一化，恢复空间轮廓，降低颗粒散射差异带来的偏差；另从二维 MSD 求水动力直径。它直接限制“利用颗粒运动自校正照明并用于粒径”的宽泛主张。主要针对空间轮廓和散射幅度，不等同于本项目同频、动态局部照明分离；文中讨论的实验也不是磁梯度 iNTA。**预印本，不标作已通过同行评议。** v1 检索题名曾为 *Motion-Based Beamshape Recovery Enables Precision Nanoparticle Sizing*，引用需明确版本。

### S3：PiSCAT 不仅有全帧 PN，也已有 ROI PN

**标题：** *PiSCAT: A Python Package for Interferometric Scattering Microscopy*。作者：Houman Mirzaalian Dastjerdi、Reza Gholami Mahmoodabadi、Matthias Bär、Vahid Sandoghdar、Harald Köstler。*JOSS* 7(71), 4024；DOI **10.21105/joss.04024**。[期刊记录](https://joss.theoj.org/papers/10.21105/joss.04024)。期刊网页写 **2022-03-31**，机构存档 PDF 首页写 **2022-03-28**，这里保留该差异，不自行统一。[机构 PDF](https://pure.mpg.de/rest/items/item_3374442_4/component/file_3374472/content)。

官方教程明确先作功率归一化以降低激光时间波动。[官方教程](https://piscat.readthedocs.io/Tutorial1/Tutorial1.html)。此次进一步读取公开源码：`power_normalized(roi_x,roi_y,...)` 可对指定矩形 ROI 求每帧总功率，用其归一化整帧，并作时间均值尺度恢复。[固定提交源码第 148—200 行](https://github.com/SandoghdarLab/PiSCAT/blob/d46928db6bece74e963510c2a992b656c08f46c1/piscat/Preproccessing/normalization.py#L148)。提交时间 **2023-04-11**，由 GitHub 公共 API 核对；不是本次已公证的首次公开日。不能把该功能首次日期直接归到 2022 年论文。任意动态粒子掩膜、多区域分别校正并非这段 ROI 代码已经完整实现的内容。

### S4：空间平场 + 时间背景漂移的低秩/稀疏方法

**标题：** *A BaSiC tool for background and shading correction of optical microscopy images*。作者：Tingying Peng、Kurt Thorn、Timm Schroeder、Lichao Wang、Fabian J. Theis、Carsten Marr、Nassir Navab。**2017-06-08**，*Nature Communications* 8, 14836；DOI **10.1038/ncomms14836**。[出版方论文](https://www.nature.com/articles/ncomms14836)，[作者机构存档全文](https://www.research-collection.ethz.ch/server/api/core/bitstreams/351518a7-4b8d-4dba-b7fe-d510f09f8907/content)。

已核对空间照明、暗场及时间背景漂移的低秩/稀疏分解。它说明“回顾式时空背景校正”已有成熟路线。其时间背景项不能未经推导就等同于任意空间变化的周期乘性增益，更不能自动保证保留磁驱动目标运动。简单移植 BaSiC 名称或低秩步骤，不能直接作为新核心。

### S5：前景掩膜辅助照明估计已有明确论文

**标题：** *Background and Illumination Correction for Time-Lapse Microscopy Data with Correlated Foreground*。作者：Tingying Peng、Lorenz Lamm、Dirk Loeffler、Nouraiz Ahmed、Nassir Navab、Timm Schroeder、Carsten Marr。首次在线 **2020-09-29**，MICCAI 2020，LNCS 12265，174–183；DOI **10.1007/978-3-030-59722-1_17**。[出版方页面](https://link.springer.com/chapter/10.1007/978-3-030-59722-1_17)，[作者机构记录](https://push-zb.helmholtz-munich.de/frontdoor.php?la=en&source_opus=60337)。

此次可读的是出版方摘要和机构摘要，未越过订阅访问：二值前景掩膜指导重加权 L1 低秩/稀疏分解，解决时序前景相关对照明估计的干扰。因此，“先分割目标再估计背景”不能泛称首创。该摘要不等于已公开 iSCAT 干涉环掩膜、磁频约束或不确定度门控；这些差异仍需全文和效果证据核对。

### S6：根据质量评价自动选择照明校正结果已有方法

**标题：** *Automatic optimization of flat-field corrections by evaluation and enhancement (EVEN) in multimodal optical microscopy*。作者：Elena Corbetta、Matteo Calvarese、Patrick Then、Hyeonsoo Bae、Tobias Meyer-Zedler、Bernhard Messerschmidt、Orlando Guntinas-Lichius、Michael Schmitt、Christian Eggeling、Juergen Popp、Thomas Bocklitz。**2026-01-07**，*Nature Communications* 17, 225；DOI **10.1038/s41467-025-68150-0**。[出版方全文](https://www.nature.com/articles/s41467-025-68150-0)，[PMC 全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12779969/)，[Crossmark 日期](https://crossmark.crossref.org/dialog/?doi=10.1038%2Fs41467-025-68150-0)。

已读全文方法相关内容：以图像质量指标和 LDA 为多个校正结果排序、选择适合各通道的结果。“多候选方法 + 自动评价择优”已有近邻。但它主要处理拼接显微图像的平场与马赛克伪影，不能推出已解决 iNTA 的扩散保真或同频分离。以粒径接近预设真值作为选法准则仍然不允许。

### S7：多区域频谱闪烁检测及“避免给未受扰区引入闪烁”已有专利

**标题：** *Spatially-varying flicker detection* / 《空间变化的闪烁检测》。发明人：**Matthew L. Trumbo（马修·L·特朗勃）**；申请人为 Pelco。公开文本：[**US20120320232A1，2012-12-20**](https://patents.google.com/patent/US20120320232A1/en)；中国同族 [**CN103583035A，2014-02-12**](https://patents.google.com/patent/CN103583035A/zh)；相关授权公告 US9088727B2 **2015-07-21**、CN103583035B **2017-05-31**。

读取美国 A1 说明书和权利要求 8–17；核对中国 A 公开号、日期与同族。已公开不同区域的时间 Fourier 分量、频率/幅度/主导性判别；说明书明确关注全帧校正可能使未受扰区域出现反向闪烁。其主要场景是滚动快门与不同捕获时刻的图像区域，已关注频率是照明及其混叠，不等同于保护真实磁运动频率。**这不是“空间门控没有价值”的证据，而是不能泛称该思路全新的重要先例。** 未核验中国当前有效权利要求及官方法律状态。

### S8：置信度、局部校正与不校正回退均已有公开

**标题：** *Method of flicker reduction*。发明人：**Andrew Dewhurst、David Hanwell**；原申请人 Apical Ltd。**US20190058823A1，2019-02-21**；相关授权公告 **US10735669B2，2020-08-04**。[A1 全文及权利要求](https://patents.google.com/patent/US20190058823A1/en)。

已读权 1、2、12 和说明书：根据图像差异判断闪烁及置信度，允许逐像素/逐区域处理；权 12 明确不认定闪烁时不应用校正。主要上下文是不同曝光的图像/序列及 HDR，而非单一曝光磁颗粒视频。故“可信才校正，不可信恒等回退”本身不是足够区别；本应用需要解释具体判别依据如何减少误删目标信号。

### S9：频谱峰 + 置信度 + 多频闪烁处理已有公开

## 3. 对下一步算法选择的约束

| 可能的小改动 | 本次可确认的近邻 | 应如何诚实定位 | 尚须验证的技术问题 |
|---|---|---|---|
| 选择无颗粒 ROI 后做 PN | S3 已有 ROI PN；S5 有前景掩膜辅助照明估计 | 有依据的改进基线，不能仅凭加入掩膜称新发明 | 盲检测掩膜是否漏掉离焦环；弱粒子漏检、少量有效背景时是否偏置增益 |
| 各象限/网格分别估计增益 | S7 的多区域闪烁频谱，S8 的区域校正 | 应与区域 PN、简单区域正弦拟合比较 | 校正边界是否扭曲 PSF；跨区轨迹是否出现定位跳变；区域大小是否敏感 |
| 按质量选择 PN/频谱/不校正 | S6 自动选择校正结果，S8 有条件回退 | 选择指标必须独立于名义粒径和仿真真值 | 评价指标能否预示定位/D 偏差，而不只是让背景更平 |
| 屏蔽磁驱动频率 | 本次所读来源未识别本应用完整实现；一般频率选择已有 S7/S9 | 只可称本应用的具体候选差异，不能称已证实的新颖点 | 同频照明时保护会拒绝真正照明；需要独立可辨识证据，否则只能诚实回退 |
| 由颗粒轨迹反求空间照明 | S2 直接近邻 | 不能再宽泛主张“运动自校准照明提高纳米粒径精度” | 本项目动态时变、磁响应、iSCAT 环形支持带来的特定区别能否证实 |

表中的“已有”指已读取文本所公开的技术内容，不表示任何一个来源已单独覆盖用户完整方案，也不表示不同来源可以不经论证任意拼接成新颖性否定。

## 4. 可作为后续开发假设的最小路线（未实现、未验收）

若六条件对照暴露出同频或局部照明的实质短板，可以优先检验下述窄问题，而不是同时堆叠多种复杂模型：

1. **先建立可复现的简单基线。** 保留全帧 PN，另加盲检测得到的背景掩膜 PN、简单分区 PN。掩膜只能由图像得到，不得使用真实轨迹或真实照明区域。只有明显优于这些近邻，进一步组合才值得讨论。
2. **研究“背景独立证据”能否改变磁频保护的结论。** 可将候选背景像素分成互不重合的估计集和验证集；只有在两者均支持相同照明分量、足够像素和估计稳定性时，才研究是否允许校正磁频附近的背景增益。无足够独立背景、结果不稳定或粒子干涉环污染时仍回退。该想法不等于已解决同频可辨识性，也不等于经检索确认的创新。
3. **局部模型增加必须由图像证据决定。** 全局模型不能解释稳定空间差异时，才尝试少量区域或平滑空间增益；对插值、掩膜覆盖和增益下限给出固定规则。空间增益变化会改变局部信噪比和 PSF 形状，必须检验跨区域轨迹及强离焦颗粒，不以背景 RMS 一项决定优胜。
4. **以测量结果保真证明必要性。** 用新种子和保留测试条件，报告照明误差、未受扰区域人工闪烁、有效定位/匹配质量、磁同步位移保留和粒径/D 结果。方法选择不得读真实粒径，不得事后以最接近 30/100/200 nm 的结果挑模型或门限。

上述路线的潜在价值仅在“针对特定测量混淆问题的具体判据及其可重复技术效果”。若掩膜 PN 已达到同等效果，应优先采用更简单且验证充分的方案，并如实缩小创新主张。不能以“必须能申请专利”为由预先保证技术区别或授权结论。
