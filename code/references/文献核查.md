# 背景校正与时间频谱融合：文献核查备忘录

检索日期：2026-11-05。目的：判断用户提供的逐像素单频FFT是否适合替代磁场iNTA背景校正，并限定可诚实表述的算法贡献。以下是针对性、有限范围检索，不是“查阅所有现有文献”的系统综述或专利新颖性检索。未运行、修改原始test.m或既有MATLAB工程。

## 1. 直接结论

**不能依据现有文献把“逐像素仅保留一个时间频率再重建”的视频，直接当成保留布朗运动的常规追踪视频。** 单频提取适合检测与驱动同步的成分；水动力粒径则依赖随机运动的统计。二者的观测目标不同。下面的锁相文献支持同步检测，不支持“单频重建后仍可无修正地沿用自由扩散MSD”。这一判断同时需要代码与数值验证，不能只引用相邻领域文章代替本工程验证。

不均匀照明校正和时间噪声处理也不是同一操作：减时间均值可以消除理想静态加性项，但不会将空间变化的乘性照明增益变为统一增益。应保留平场/背景比值归一化的物理含义。[BaSiC原论文](https://push-zb.helmholtz-munich.de/deliver.php?id=19126)

**FFT、功率归一化、锁相检测、低秩背景均已有先例，不能单独声称首创。** 比较稳妥的候选贡献是：在磁驱动iNTA中，从空间共同成分估计周期照明，校正这个背景而不把每个像素的布朗运动视频变成单频视频，并通过成像→定位→粒径的独立验收检查该处理是否保留扩散信息。是否有实质改进仍须由本工程消融结果决定。

## 3. 最小融合建议（方法建议，不是已完成结果）

保留当前中值/掩膜背景与对比度归一化。将test.m的频谱分析思路移到“背景共同分量”上，而不是用单频重建代替每帧含粒子的视频：

1. 从许多空间位置或分区的背景比值稳健估计共同强度变化；可用粒子掩膜减少运动目标对估计的影响。估计器不读取真粒径、真轨迹或渲染器的真背景。
2. 通过FFT识别候选周期成分，再以明确频率的正弦/余弦回归估计该共同分量；对非整周期数据不把最近DFT栅格等同于真实频率。实际采用哪一种应按实现和测试如实写。
3. 只从原帧中去掉/除去估计出的加性/乘性背景。保留原帧数、时间戳与未投影的粒子变化，随后进入原RVT、定位、链接及磁场修正。
4. 对磁驱动频率及其谐波保持谨慎：它们可能包含真颗粒响应。保护这些频率可减少误删，但也意味着无法校正恰好同频的照明污染；必须测试并报告这一盲区。若使用纯空间共模判据而不保护频率，则仍要验证不会将真实磁响应作为照明消掉。
5. 单频幅相图可作为附加诊断输出，但要标为“周期响应/背景频谱图”，不称为普通粒子轨迹视频，也不将幅相图直接当作MSD输入。

建议验收至少包括：A原算法，B直接单频重建（反例/消融），C无频谱选择的普通功率归一化，D提出的融合方案；同一原始视频做成对比较。干净基线应不劣化，动态照明压力测试应降低指定干扰，同时检查定位/丢失率/D/粒径，而不只比较图像SNR。采集设置、频率范围和阈值在正式验收前冻结。对于原仿真没有的动态光照，需要显式加入可关闭的压力测试，不能把人为设置说成已观察到的真实设备噪声。本次最终实施沿用上一版基准种子，因此属于回归及配对压力复测，不能称为全新独立保留样本。实际实现以[融合方法说明](../融合方法说明.md)为准。

可在报告中使用的保守表述：**“面向交变梯度磁场iNTA的周期照明共模校正与扩散信息保持验证”**。它是本工程拟验证的组合改进，不代表已经证明全球首创。若同原算法相比没有实质收益，应如实报告，而不是仅因代码不同就称创新成功。

## 5. 中文原始来源补查：区分空间FFT与时间单频投影

补查日期：2026-11-05。谭浩、许传龙、张彪、王式民。**基于近场散射的颗粒粒径分布测量**。《北京航空航天大学学报》2017，43(2)：381–387。DOI：[10.13700/j.bh.1001-5965.2016.0110](https://doi.org/10.13700/j.bh.1001-5965.2016.0110)。[原期刊页面](https://www.spacejournal.cn/bjhkhtdxxb/article/doi/10.13700/j.bh.1001-5965.2016.0110)。作者、卷页、DOI和摘要由原期刊页面核实。

该工作对差分散斑图作**空间**FFT以获取角散射强度，再使用Chahine算法反演微米颗粒尺寸分布。它说明Fourier分析可以用于另一类有明确观测模型的颗粒测量，但其空间频率、角散射反演与本任务的逐像素时间单频重建后MSD不同。因此不能据“FFT也能测粒径”支持 `test.m` 直接替代iNTA背景处理，也不将该论文列为本工程已实现算法或纳米粒径精度的证据。此次仅核查原期刊可访问的书目信息与摘要，不推测未核读的全文实现细节。
