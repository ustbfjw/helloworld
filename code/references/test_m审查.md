# test.m 独立审查与可替换性结论

## 结论

不能将原脚本的单频重建输出直接替换当前iNTA背景校正输出，再按原MSD公式求D。可以保留其“逐时间序列频谱分析”的思想，用来诊断或估计有证据支持的周期性公共照明变化；该融合必须保留逐帧宽带颗粒信号，并另行做盲端到端验收。

本结论基于源代码、解析公式与实际MATLAB R2024b合成实验；没有执行原脚本，也没有访问其硬编码BMP目录。下面的合成实验不是完整iSCAT粒径验收。

## 解析反证

设单个像素的去均值序列为x_p[n]，仅保留第k个正频率和对应负频率，则非DC、非Nyquist情况下：

r_p[n] = (2/N) Re{X_p[k] exp(i 2πkn/N)}
       = A_p cos(2πkn/N) + B_p sin(2πkn/N)。

因此，整段重建视频每帧都只是两个固定空间图样A、B的线性组合，时间秩最多为2。DC与Nyquist情形甚至最多为1。随机布朗运动在原相机图像中的逐帧变化不能完整保留在这样的单频子空间中。即便把targetFreq改成10 Hz，也只保留与该频率有关的成分，而不能自动分离磁泳和布朗扩散。

作为直观对应，正弦坐标x=A cos(ωt+φ)的相位平均MSD为A²[1−cos(ωτ)]，并非2Dτ；小τ极限主要为τ²。故不能在单频重建后不修改观测模型就照搬原MSD线性拟合。

## 已运行的合成实验

运行文件：[tests/review_fft_replacement.m](../tests/review_fft_replacement.m)；交付日志：[run.log](../04_results/development_fft/run.log)；机读数据：[fft_replacement_review.json](../04_results/development_fft/fft_replacement_review.json)。全部断言通过，MATLAB退出码0。

1. **坐标类比，非相机盲追踪：** Fs=5000 Hz、N=5000、200条独立一维布朗轨迹，输入D=4.396980 µm²/s。原前4个lag的汇总MSD估计D=4.388508；只保留10 Hz后得到0.017454587（原值0.3977%），只保留420 Hz后为0.011291285（0.2573%）。这些数值只证明单频限制改变了扩散统计，不能当作原iSCAT算法的实测误差。
2. **移动高斯图像，非iSCAT光学：** 对32×32×2001图像应用原FFT核心，单频图像到解析秩2子空间的相对残差为3.50e−14，第三与第一奇异值比6.66e−16，保留的去均值时间能量为2.0368e−5。
3. **平场反证：** 同一420 Hz变化信号的照明幅度倍增2，输出FFT幅值也倍增2，说明单频提取没有消除乘性空间照明差异。
4. **实现边界：** Nyquist输入幅值2被正确恢复；DC在预先去均值后接近零，符合脚本处理逻辑。

## 建议的最小融合范围

本节保留实现前的设计建议，不表示其中每项已原样实现。最终实现使用四象限稳健中值，没有在公共照明估计阶段显式掩膜颗粒；正式验收沿用上一版基准种子，属于回归和配对压力复测。准确实现、参数及验证范围以[融合方法说明](../融合方法说明.md)为准。

维持原静态平场估计B、对比度计算、RVT、检测、链接、磁场修正及D估计接口。对排除颗粒区域的背景像素，估计公共光强比例g(t)≈median_background[I(x,y,t)/B(x,y)]。频谱只用于诊断公共光强中的窄带变化，或者估计经验证的周期性公共照明参数；若需要精确非bin频率，可用已知频率的sin/cos回归而不是盲目最近bin替代。随后对原逐帧视频作正值g(t)归一化，再进入既有流程。

这是一个适用范围受限的公共乘性照明模型：不能宣称去除了所有空间非均匀动态背景，也不能宣称消除了散粒噪声。没有真实周期照明伪影时，应接近原算法；不能为了展示改善而删除布朗频谱。频谱、鲁棒空间统计、平场归一化均为已有工具，本任务中的组合与验证最多先称“本项目方法扩展/候选改进”，不能未经查新声称首创。

建议预先固定验收：零伪影近恒等；同一视频注入已知公共乘性闪烁后的paired背景误差和定位/粒径误差；不使用真位置/真D/标称粒径选择参数；独立种子完整图像链路；保留基线、失败候选和全部实际结果。若磁驱动与照明同频，应明确可辨识条件，不能将任何同步分量自动判为噪声。
