这里保存的是失败时的协议和其源码哈希，不能要求修复后的 `baseline_snapshot/` 与旧协议全部吻合。正式结果使用自己的冻结协议，二者应分别追溯。首次失败不计入后续正式样本数量；是否完整和效果如何，应读取对应正式结果与独立审计。
